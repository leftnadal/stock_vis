## Context / Agreed Direction

전체 목적은 판단 당시 근거와 실제 결과를 대조하여 다음 판단을 개선하는 것이다. 사용자는 별도 학습 사용 장부나 새로운 상태 분류를 만들기보다, 기존 기록의 중요한 판단 이유에 과거 자료의 참조·명시된 활용 이유·현재 판단·한계를 연결하는 방향에 동의했다.

기록에서 확인하려는 핵심은 ‘어느 자료를 어떤 용도로 참고했고, 어떤 판단을 했으며, 무엇은 아직 확인하지 못했는가’다. 기존 정보는 복사보다 참조를 우선하고, 상세 평가와 근거 원문은 해당 기록의 책임 범위에 둔다.

## Material Conditions Preserved

- 자료 접근·인용, 작성자가 설명한 사용 이유, 관찰된 변경, 판단 개선 효과를 구분한다. 자기 설명이나 변경 사실만으로 과거 기록의 인과적 개선 효과를 입증하지 않는다.
- 판단 유지·보류·중요한 비적용 이유도 이후 판단 복원에 필요하면 남긴다. 모든 검색 결과에 수동 기록을 요구하거나 변화 횟수를 학습 품질로 삼지 않는다.
- 당시 이유를 사후 결과에 맞춰 만들거나 덮어쓰지 않는다. 당시 기록의 결손과 후속 해석을 구분한다. 비공식 기록의 활용은 공식 권위나 실행 권한을 부여하지 않는다.

## Alternatives / Remaining Limits

링크만 남기는 안보다 활용 맥락을 보존하고, 모든 검색을 별도 장부에 남기는 안보다 중복과 작성 부담을 줄이는 방향이다. 이 정도의 선택적 기록이 실제 재구성에 충분한지, 기록 부담과 판단 개선 효과가 적절한지는 아직 검증되지 않았다. 대안·반론의 상세는 Checkpoint 04를 참조하며 다시 복제하지 않는다.
