## 대상·방식·예산
- **대상**: null **192일** = 구간내 **154**(EARLIEST+1000cap이 창 뒷날 삼킴, 요일 편중 금65·목47·수30·화12) + 뒷단 **38**(2025-12-10~2026-02-19, 백필종료~라이브 가동 사이 미수집 연속 공백).
- **방식**: `backfill_broad_news --dates` — 각 명시일을 **1일 독립 창**으로 재수집(창 논리 EARLIEST 보정 우회, 주말·공휴일 낭비 0, `--skip-covered` 멱등).
- **예산**: **20 req/실행** (AV 25/day − broad beat 2 − 여유 3). 1일당 ≈1 req(limit 1000, 과거 고볼륨 <1000이라 saturation 없음).
- **실행 시각**: **22:00 KST 이후**(rolling 24h 쿼터가 broad beat @01:00 UTC와 충돌 회피).
- **총 소요**: **10 달력일**(192÷20, 마지막 배치 12일).

## 완료 판정 (★일 단위 존재 검증 — "창 완료" 아님)
- 각 배치 실행 후 `"백필 대상: N창"` 확인 → 배치 내 **N=0 = 그 배치 완료**.
- 최종: null 192일 각각 `NewsArticle.filter(published_at__date=D)` **> 0** (잔여 0). 그 후 **C-L3-REGEN-V2** 진입.
- ⚠️ D-CN-COMPLETE 폐기 교훈: "122/122 창 완료" 같은 창 단위 판정 금지 — **일 단위 존재**로만 완료 선언.
