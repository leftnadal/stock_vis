## 1. 결정 선언

**SWAP-REVIEW 트랙을 신설한다** — "보유 종목 X를 계속 들 것인가, 판다면 무엇으로 바꾸는가"에 답하는 교체 검토 체계. 네 문장으로:

1. **계산은 분산, 화면은 통합.** 렌즈별 수치는 소유 앱(타이밍=monitor · 테마=chain sight · 가치=가치분석 · 배분/마찰=portfolio)이 계산하고, 비교 서피스는 이를 읽기 전용으로 병렬 표시하는 FE 컴포지션이다. BE 결합 0, monitor leaf 유지.
2. **판정의 주연은 통계가 아니라 계약이다.** 결정을 지는 것은 사전 커밋된 매수 근거의 생사(계약층)와 교체 마찰의 산술(마찰층)이며, 통계층은 지지/반대/**침묵** 3값의 조연이다.
3. **검토는 이벤트가 아니라 상태다.** 트리거로 열리고, 매일 델타만 갱신하며, 해소·사용자 판정·기한 도달로만 닫힌다.
4. **성공 지표는 교체 전환율이 아니라 무기록 결정률 0%다.** 사용자가 어느 경로로 결정하거나 회피해도(실행·보류·재커밋·우회 매도) 기록이 따라간다. 시스템은 결정을 막지 않는다 — 기록한다.

## 2. 동기

- 사용자 니즈 직접 발화(GEV 익절 검토 · IONQ 근거 소멸 검토) — 후보 중 유일한 실수요 실증.
- 처분 효과 방어의 미완 구획: 진입은 규율화됐으나(빌더·사전 커밋) **보유 지속과 교체 판단은 무규율 지대**였다(Odean 1998 — 패자 장기 보유 방어가 본 트랙).
- 계획 세션 자기 점검에서 식별된 설계 결함 12건의 수리를 원칙으로 승격(§3), RECON-SWAP-0813 실측으로 빈칸 충전.
- **행동 스트레스 테스트(ST-1 본전 앵커 · ST-2 반론 악용 · ST-3 시스템 우회 · ST-4 형해화)에서 식별된 누수 4건의 방어(패치 P-1~P-5)를 설계로 승격.**

## 3. 확정 스펙 (불변식)

### 3.1 판정 위계
계약층(주연) > 마찰층(보조) > 통계층(조연). 통계층은 3값만 갖는다: 지지 / 반대 / **침묵**. 모든 통계 수치는 구간 의무 병기, **구간이 0을 포함하면 침묵을 선언한다.** 렌즈 가중 합산 단일 점수는 영구 금지. 판정 카드에는 **반론 의무 슬롯**(반대 행동의 최강 논거, 동분량)을 병기한다.

### 3.2 판정 주체 분리 강화 (v2 확장)
- **결정 일지 강제**: 실행(마감·재커밋) 전 1문장 작성 전 실행 버튼 비활성. 입력 품질 검증(최소 글자 수 등)은 **도입하지 않는다** — 게임화 방지. 일지의 가치 회수 시점은 입력이 아니라 **회고**다: 마감 회고 화면이 당시 일지를 **원문 인용**한다(P-4).
- **보류 기회비용 계기판(P-1)**: 보류 2회째부터 판정 카드 최상단에 의무 표시 — 보류 누적 일수 · 그 기간의 보유/후보 성과 · 격차 실현분.
- **검토 최상단 고정(P-5)**: 열린 검토는 브리핑 최상단 고정 + 방치 일수 표시.
- **무단 마감(P-3)**: Wallet read-only 동기화로 시스템 외 보유 변경 감지 시 "무단 마감" 상태를 생성하고 **중립 톤**으로 사후 일지를 요청한다. 순응률 원장에 기록. 차단·경고 톤 금지 — 우회는 막을 수 없으며 막는 척하지 않는다.
- **시장 극단일 레인 안내**: 시장 z 극단일에는 판정/판단 불가 카드가 "이것은 종목 질문이 아니라 시장 질문 — 도망 판단은 market_pulse 소관" 안내를 표시한다(v0은 문구 1줄).
- **순응률**: 시스템 판정 대비 사용자 결정 일치율 기록, 100% 접근 시 경고 표시. 매매 지시는 영구 금지(3-B 계승).

### 3.3 "판단 불가"의 정식화
회색 지대에서 시스템은 결론을 지어내지 않고 **"판단 불가"를 정식 판정값**으로 반환하며, 다음 관측 조건(무엇이 성립하면 재판이 서는지)을 제시하고 그 조건을 트리거로 예약한다.

### 3.4 수치 출처 규율
전 수치에 출처 3색 배지(수동/규칙/통계) 의무. 수동 입력값 유통기한 90일 — 경과 시 재확인 요구. 어림 산출에는 "어림" 배지.

### 3.5 검토 상태 객체
트리거 → 검토 열림(중복 발화 금지 · 매일 델타 갱신 · 무변화 압축) → 종결 3경로(해소/사용자 판정/기한 도달). 사용자 조작 > 자동. 검토 지속 일수·보류 횟수 기록(캘리브레이션 재료).

### 3.6 히스테리시스·파라미터 대장
판정 성립/해제 이원 임계 + 부활 비대칭 지속성. 모든 임계·버퍼·지속일은 노이즈 플로어 실측에서 도출(z 재계산 기반 — RECON 확정)하고 출처와 함께 **파라미터 대장**에 등재. 무출처 매직 넘버 금지.

### 3.7 갭 규칙
실측(E-1): 6종 갭 체질 유니버스 대비 ~3배, IREN >3% 갭 33.7%. **스윙 손실 산술은 차일 시가 체결 가정 기본값**, 갭 체질 배지(유니버스 대비 배수) 의무 표시.

### 3.8 커밋 불변 (v2 확장)
- 진입·목표·손절·기한은 사용자 변경 외 불변. 사전 커밋된 이동 규칙(트레일링)만 기계 이동.
- 근거 소멸 후의 홀드는 **재커밋**(새 근거의 새 시나리오) 필수 — 근거 없는 보유 상태의 존속 금지.
- **반론의 조건화(P-2a)**: 반론 슬롯을 홀드 사유로 채택하면 그 반론은 **관측 가능 조건으로 강제 전환·등록**된다(예: "테마 상승 지속" → 테마 점검 D-30). 반론도 새 계약이다 — 공짜 홀드 금지.
- **기회 포기 기록(P-2b)**: 목표 상향 재커밋 시 구 시나리오는 "**원 목표 도달 — 익절 기회 포기**"로 마감 원장에 기록된다. 골대를 옮겨도 원 골은 지워지지 않는다. 재커밋 후 원 목표 회귀율은 v2 원장의 캘리브레이션 항목.

### 3.9 경계
비교 서피스는 FE 컴포지션 — monitor 외부 BE 소비자 0 유지. serializer 계약 테스트 신설(v0.5 조건). 앱 간 직접 import 금지·통로 별도 결정 유지. 수량·비중은 portfolio 소관.

### 3.10 호흡별 방법
스윙(~2주–1개월): 구조층 주연(레벨 트리거·무효화·목표·기한 청산), 헤드라인 = 손익분기 승률 vs 실측 승률, 모멘텀 기대수익 표시 금지(반전 구간), 상위 추세 필터, 패턴은 수동 태그만(E계열 격리 유지). 포지션(1–6개월): Grinold α = IC × σ × z. 코어(6개월+): Grinold + 가치 갭.

### 3.11 통계층 산출
IC 이중 트랙: 자기 패널(6종×~132일) + 유니버스 신호 IC — **즉시 가용분은 EODSignal 520종×~6개월**이며, **~3년 확장은 DailyPrice(747종) 기반 신호 소급 재계산을 전제**한다(기저율 엔진과 동일 재계산 계열 — v1.5 유니버스 판정에 본 전제 포함). 승률은 베타-이항 수축 **구간 표시만**. 기저율 조건부 장착 — 국면 라벨 의무, 하락 국면 셀 공백 시 해당 호흡 침묵. 무조건 기준선 상시 병기.

### 3.12 진단의 규칙층 회수
진단은 규칙 소관, LLM은 문장화만(수치 생성·순위 변경·진단 권한 없음). v1 = 2단 분해(시장 z: SPY·VIX 확보 / 종목 잔차), 테마 성분은 SPIN-1 후 3단 확장. LLM 출력에 기계 검증(수치 대조·지시어 린트) 게이트 필수 — C-4 재검증 후 미구현 확정 시 v0.5 신설.
