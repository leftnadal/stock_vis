# SLICE 20B-F1 지시서 — 매수일 선택화 + "지금부터 추적" 폴백 (도그푸딩 피드백 #1)

> **배치 위치:** `docs/portfolio/coach/slice20b/SLICE20BF1_INSTRUCTION.md` — 실행 세션, repo 배치 필수.
>
> **세션 종류:** 실행 세션(미니 슬라이스). 결정은 닫힘(§4 — 사용자 확정 2026-07-24). 재오픈 금지, STEP 0가 전제를 깨면 HALT.
>
> **왜 이 슬라이스인가:** 병진의 라이브 온보딩 첫 시도에서 나온 **도그푸딩 피드백 #1** — 보유 입력 시 매수일이 필수인데 실제로는 기억 못 하는 경우가 많아 입력이 막힌다. 매수일을 선택 필드로 바꾸되, 매수일이 비면 KRW 취득 환율을 지어내지 않고 **"입력일부터 추적"**한다(A안). 이 수정이 배포돼야 병진 온보딩 → 원장 축적이 시작되므로 최우선 미니 슬라이스다.
>
> **⚠️ 새 환경 제약 (2026-07-24 발견 — 이 슬라이스부터 적용):** **dev와 prod가 동일 물리 DB(stock_vis)를 공유한다.** 또한 beat 2종이 등록(또는 곧 등록)돼 `portfolio_goal` 보유 유저를 매일 밤 처리한다. 따라서 이 세션에서: (1) dev 설정으로의 `migrate`·shell 쓰기 = **prod-write다** — 금지, (2) 라이브 캡처용 데모 유저는 **goal을 갖는 순간 nightly 대상**이 된다 — 캡처 후 즉시 삭제·증명 필수.
>
> **base:** `origin/main = 39c20c3`(런북 랜딩 시점 — 재측정 대상). 3축: pytest 947급/tsc 0/vitest — STEP 0 실측이 baseline.

## 0. 산출물 정의 (DoD)
1. **매수일(first_bought_at 계열 — 실명은 STEP 0) 선택화:** 프론트 폼 optional 표시 + serializer 검증 완화 + (모델이 null=False면) null=True 마이그레이션 **파일 생성까지**. 기존 데이터·다른 필드 무변경.
2. **A안 폴백:** 매수일 미입력 보유의 KRW 취득 환율(acquisition_fx_rate 계열) = **입력(생성) 시점 spot**. 매수일 있는 보유는 기존 로직 그대로(폴백은 미입력 경우만). 폴백 적용 사실이 데이터로 구분 가능해야 함(예: 매수일 null 자체가 표지 — 별도 필드 발명 금지, 기존 구조로 충분한지 STEP 0 판단).
3. **화면 사실 표기:** 매수일 미입력 보유에 "매수일 미입력 — 입력일부터 KRW 추적" 안내(모달 힌트 + 목록 표지 중 하우스에 맞는 최소 형태). 과거 수익을 아는 척하지 않는다.
4. **테스트:** 미입력 생성 → 폴백 환율 기록 → KRW 계산 정상 포함 / 입력 생성 → 기존 경로 불변 / serializer optional 경계. 전부 **pytest test DB**(공유 DB 무접촉).
5. **라이브 캡처(상시 규칙) + 청소 증명:** 캡처용 데모는 만들되 **같은 세션에서 cascade 삭제 + `portfolio_goal` 보유자 쿼리로 잔존 0 증명**을 캡처 보고에 포함. (beat 대상 오염 차단 — s20b_demo 재발 방지.)
6. **거버넌스 등재:** TASKQUEUE/DECISIONS에 `DEV-PROD-SHARED-DB` 기록 — "dev 검증·migrate·shell 쓰기 = prod 접촉으로 간주, 데모 시드는 생성 세션이 삭제·증명 책임, '정리 완료' 주장은 검증 쿼리 동반 필수".
7. **회귀:** 3축 기존 깨짐 0, 아키텍처·동결 0, `--check`는 신규 1개(선택화 마이그레이션)만.

## 1. 절대 규칙 (넘으면 HALT — §5)
- **공유 DB에 migrate·쓰기 금지.** 마이그레이션은 파일 생성 + test DB 검증까지. **실 DB 적용은 병진 수동**(런북 S1 절차 준용 — 닫기 보고에 적용 명령·G1 확인 쿼리를 후보로 첨부).
- **A안 외 의미 변경 금지.** 매수일 있는 보유의 계산 경로·기존 13모델·엔진·계약 필드 불변. 소급 재계산 없음.
- **환율 폴백에 예측·근사 발명 금지.** 입력일 spot(ExchangeRate 최신 close)만. spot 부재 시(주말 등) 직전 영업일 close — 그 이상 지어내지 않는다.
- **캡처 데모 = 생성한 세션이 삭제·증명.** goal 가진 데모를 남기고 종료 금지.
- 메모리 신뢰 금지 / worktree·`monorepo/sess-20bf1-*` / prod·파괴적 작업 유보 — 기존 규약 그대로.

- (b) **계층 실측:** 매수일 필드 실명·모델 null 여부 / serializer required 여부 / 폼 required 여부 → 고칠 계층 목록 확정.
- (c) **acquisition FX 경로:** 19b의 취득 환율이 언제·무엇으로 기록되는지(매수일 의존인지, 생성 시점인지) — A안 폴백의 정확한 삽입 지점. KRW 수익 계산이 이 값을 소비하는 경로 1개 표본.
- (d) spot 조회 하우스 경로(ExchangeRate 최신 close 취득 함수 존재 여부).

## 5. HALT 트리거
- acquisition FX 경로가 실측 불가하거나 A안 삽입점이 기존 로직 수정 없이는 불가능(가산 전제 파기).
- 선택화가 매수일-필수를 가정한 다른 소비처를 깨뜨림(STEP 0 (c) 표본 외 소비처 발견 시 전수 확인 후에도 충돌).
- 공유 DB 쓰기 없이는 진행 불가한 지점 / spot 부재 케이스가 규칙(직전 영업일)로 안 닫힘.
