## §0 — 전제·불변 조건

- **승인 근거:** G1.5 비준 + 판정 A(partial_match 등급 신설) 자동 결정 — 가중합 4.80, 마진 1.70 > 1.00.
- **불변:** V-A 결정론 계약 · LLM 호출 0 · DB 쓰기 0 (dry-run 전용) · Gate 2 정지 유지.
- 본 지시서는 `docs/instructions/`에 커밋된 후에만 소비 가능 (0번째 게이트).

## §1 — 기준 사전 고정 (재분류 실행 전 커밋으로 고정)

- **`partial_match` 정의** = G1.5 ③의 prefix 결정론 규칙 승격 + 하한 추가:
  - 정규화 접두 연속 매치가 인용 길이의 **≥70%**, **그리고**
  - 발산 형태가 **절단/mid-word 계열**.
- 하한(70%) 미달 tail 발산은 **not_found 유지.**
- **판정 체계** = `verified` / `normalized_match` / `partial_match` / `not_found` (+ `missing_source` 계열 2종 예약).
- **partial은 접지 성공에 합산 금지** — 별도 등급으로만 집계·보고.
- 임계 15%는 손대지 않으며, 재분류 후 **잔여 순수 not_found**에만 적용한다.

## §2 — 재분류 dry-run

- 437건 **전량** 재판정 → 신 분포 산출 (**명목·유니크 병기**).
- 잔여 순수 not_found율 산출 (명목·유니크 병기) → 15% 재판정 입력.

## §3 — 샘플 입증

- partial_match에서 **층화 20건** 추출 — 인용 vs 원문 나란히 배치 + 발산 지점 표시 육안 리포트.
- 목적: "접두 verbatim + 꼬리 절단"임을 사람이 직접 확인 가능하게 — "절단이지 조작 아님" 입증.

## §4 — 마이그레이션 정합

- 0002 상태 필드가 `partial_match` 값을 수용하는지 확인.
- 필요 시 **additive 수정만** 허용 (`makemigrations --check` clean 유지). stock_vis DB 적용은 Gate 2 범위 — 이 세션에서 적용 금지.

## §5 — 정리 2건

- **V-B**: TASKQUEUE에 트리거 대기 등록 — 문안: "잔여 not_found율 >15% 재발 시 재스코프, 범위 = 합성/재서술 클러스터(~13 유니크)". 선제 도입 금지.
- **prompt v2**: Gate 2 범위 존치 — 표적 = tail 발산 방지 문구 (G1.5 부수② 문구 초안 인용).

## §6 — 종료 조건

- §2의 잔여율이 수치상 ≤15%이면 **Gate 2 사인오프 요청서**를 작성·커밋하고 **정지**:
  - 요청서 구성: 백필 실기록 + 마이그 stock_vis 적용 + flag-on 1 filing + prompt v2 (한 배치) — **실행 계획·롤백 절차 포함.**
- **Gate 2 실행은 감독 비준 후에만.** 요청서 작성·커밋은 문서 산출일 뿐 판정 선언이 아니다 — ≤15% 최종 판정·비준 권한은 감독 세션에 있다.
- 잔여율 >15%이면 요청서를 작성하지 않고 분포·원인 보고 후 정지.

## 커버 지시서와의 정합 (재발행 시점 명시)

- 소비 순서·STEP 0·소급 R1/R2·HALT 조건·보고 형식은 `sec_beta_g16_retrieval_cover_directive.md`가 고정한다.
- **한 지점 조정:** 커버의 "실행 세션은 수치만 보고, 자체 판정 금지"는 본 base §6과 다음과 같이 정합한다 — 수치상 ≤15% 충족 시 §6의 사인오프 **요청서 작성·커밋까지는 실행 세션 범위**이고, 판정 선언·Gate 2 착수는 여전히 감독 몫. 이 조정은 base가 커버에 선행 발행된 문서이므로 base §6이 우선한다.
