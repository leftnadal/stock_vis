## 3. ⚠️ 실행 트리 의존 (중요)

렌더 수집은 **`sv-web-runtime/frontend/node_modules`의 playwright**를 쓴다. dogfood가 도는 `sv-worker-runtime`에는 `frontend/node_modules`가 **없다**(실측 2026-09-02).

- `collect_rendered.py`가 node를 `sv-web-runtime/frontend`를 cwd로 실행하고, ESM이 `NODE_PATH`를 무시하므로 playwright 진입점을 **절대 경로로 주입**한다.
- 따라서 **web 런타임 트리도 `sv sync` 대상**이어야 한다(스크립트 파일이 그 트리에 있어야 함). 현재 web 트리 HEAD = `8489b2d0`로 worker와 동일하니 통상 `sv sync`면 충족된다.
- web 트리에 `npm ci`가 풀리지 않은 상태가 되면 렌더 수집은 **사유를 담아 실패**하고 루브릭은 "측정 불가"로 보고된다(1단계·메일은 그대로).
